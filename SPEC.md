# Сайт за хамалски услуги — задание за разработка

Версия за разработка на документа „Сайт за хамалски услуги — спецификация“. Ако нещо тук е неясно или си противоречи, питай, вместо да гадаеш.

## 1. Обхват

Правим **вариант Б**: статичен сайт с 8–10 страници, ценоразпис, калкулатор за ориентировъчна цена и форма за запитване.

Основната цел на сайта е посетителят да се обади или да пише във Viber/WhatsApp. Когато има избор, печели решението, което прави това по-лесно.

Извън обхвата сега: админ панел, база данни, собствен сървър, онлайн резервация, онлайн плащане, качване на снимки във формата, английска версия, известия в Telegram.

## 2. Данни за фирмата — само placeholder-и

Фирмените данни още не са известни.

- Всичко, свързано с фирмата, стои само в `src/data/`: име, град, телефон, Viber, WhatsApp, имейл, адрес, ЕИК, регистрация по ДДС, работно време, райони, цени, услуги, отзиви.
- Всяка неизвестна стойност е ясен placeholder с коментар `// TODO`, например `city: '[ГРАД]', // TODO` и `phone: '+359000000000', // TODO`.
- Не измисляй цени, отзиви, снимки или фирмени данни. Отзивите са 3 примерни записа с `[Име]` и `[Текст на отзива]`.
- Снимките са placeholder изображения, докато клиентът не даде истински.
- Докато цена е 0, на сайта на нейно място стои „… €“, а калкулаторът показва, че цените предстоят.

## 4. Начална страница — секции по ред

1. **Горна лента** — лого, меню, телефон като бутон. На телефон: лого, „Обади се“ и бутон за меню.
2. **Първи екран** — H1 „Хамалски услуги в [град]“, едно изречение обещание, „от … €/час“, бутони „Обади се“ и „Viber“, снимка на екипа и буса.
3. **Услуги** — карта за всяка услуга: икона, едно изречение, „от … €“, линк към страницата ѝ.
4. **Цени накратко** — 3–4 най-търсени цени и бутон „Изчисли цена“ към `/ceni#kalkulator`.
5. **Как работим** — 4 стъпки: обаждаш се или пращаш снимки → получаваш цена → идваме в уговорения ден → плащаш след работа.
6. **Защо нас** — 3–4 конкретни факта от `src/data/site.ts` (placeholder-и).
7. **Снимки от реални обекти** — 6–9 снимки.
8. **Отзиви** — 3–5 отзива и линк към Google профила.
9. **Райони** — квартали и градове, в които работят.
10. **Често задавани въпроси** — 5–7 от `src/data/faq.ts`: как се формира цената; колко време отнема двустаен апартамент; опаковате ли и разглобявате ли мебели; работите ли в почивни дни; как се плаща и има ли фактура; какво става, ако нещо се повреди.
11. **Финален призив** — „Обади се сега“ и формата за запитване.
12. **Футър**.

| Хамалин | на час | от … € |
| Бус с шофьор, в града | на час | от … € |
| Минимална поръчка | — | … часа |
| Етаж без асансьор | на етаж | … € |
| Извън града | на км | … € |

| Пакет | Включва | Цена |
| --- | --- | --- |
| Гарсониера | … хамали + бус, до … ч | от … € |
| Двустаен | … хамали + бус, до … ч | от … € |
| Тристаен | … хамали + бус, до … ч | от … € |

Правила за показване:

- Цените са само в евро, цели числа, формат „от N €“.
- Под всяка таблица: „Цените са ориентировъчни. Точна цена по телефона или след снимки във Viber.“
- До цените стои дали включват ДДС и разноски. Текстът идва от `site.ts` (`vatNote`, TODO според регистрацията на фирмата).

## 7. Калкулатор — `src/components/Calculator.tsx`

Въпроси:

1. Какво местите: гарсониера, двустаен, тристаен, къща, офис, отделни вещи.
2. Етаж на тръгване и на пристигане; има ли асансьор на всеки адрес.
3. В града или извън него; ако е извън — км.
4. Допълнително (отметки): демонтаж и монтаж, опаковане, извозване на стари мебели.

Формулата е чиста функция `estimatePrice()` в `src/lib/estimate.ts`, покрита с тестове:

```text
P = max(h, h_min) × (n × c_p + c_v) + f × c_f + d × c_d + E
```

- `h` — часове за типа обект: долната граница се смята с `hours[0]`, горната — с `hours[1]`
- `h_min` — минимална поръчка в часове; `n` — брой хамали за типа
- `c_p` — хамалин на час; `c_v` — бус с шофьор на час
- `f` — етажи без асансьор: (етаж на тръгване, ако там няма асансьор, иначе 0) + (етаж на пристигане, ако там няма асансьор, иначе 0); партерът е етаж 0
- `d` — км извън града (0 в града); `c_d` — цена на км
- `E` — сбор на избраните допълнителни услуги

Резултатът е „между X и Y €“: X се закръгля надолу, Y нагоре до 5 €. За „офис“ и „отделни вещи“ не се смята диапазон — показва се минималната поръчка и подкана за обаждане.

Под резултата: „Ориентировъчна цена. Точната зависи от багажа — обадете се или пратете снимки.“ и бутоните „Обади се“ и „Изпрати запитване“. Под калкулатора на `/ceni` стои формата; „Изпрати запитване“ скролира до нея и попълва скритото поле с избраното и с диапазона.

```ts
// src/data/pricing.ts — единственото място с цени (в евро)
// TODO: всички стойности идват от клиента
export const pricing = {
  porterPerHour: 0,   // c_p
  vanPerHour: 0,      // c_v
  minHours: 0,        // h_min
  minOrderPorters: 0, // хамали за минималната поръчка
  perFloor: 0,        // c_f
  perKm: 0,           // c_d
  jobs: {
    studio:    { label: 'Гарсониера', porters: 0, hours: [0, 0] },
    twoRoom:   { label: 'Двустаен',   porters: 0, hours: [0, 0] },
    threeRoom: { label: 'Тристаен',   porters: 0, hours: [0, 0] },
    house:     { label: 'Къща',       porters: 0, hours: [0, 0] },
  },
  extras: {
```

## 8. Форма за запитване — `src/components/QuoteForm.tsx`

| Поле | Задължително | Бележка |
| --- | --- | --- |
| Име | да | |
| Телефон | да | български номер: +359… или 0… |
| Дата на преместване | не | `type="date"` |
| Откъде | не | квартал или град |
| Докъде | не | квартал или град |
| Какво се мести | не | свободен текст |
| Резултат от калкулатора | — | скрито поле |

- Изпращане през Web3Forms; ключът е в `PUBLIC_WEB3FORMS_KEY` (`.env`, с `.env.example` в репото).
- Защита от спам: honeypot поле според документацията на Web3Forms.
- Под бутона: „Изпращайки формата, приемате данните ви да се използват само за отговор на запитването.“ и линк към `/poveritelnost`.
- След успех: пренасочване към `/blagodarim` — „Благодарим! Ще ви се обадим до … минути в работно време.“ (минутите са в `site.ts`, TODO).
- При грешка: ясно съобщение и телефонът като алтернатива.
- Формата стои на `/kontakti`, в края на началната страница и под калкулатора на `/ceni`.

## 9. SEO

- `<html lang="bg">`; уникални `title` и `description` за всяка страница, с услуга и град, например „Хамалски услуги [град] — от … €/час | [фирма]“.

- JSON-LD `MovingCompany` в `Base.astro` с данните от `site.ts`: име, телефон, адрес, работно време, `areaServed`, `url`.
- `@astrojs/sitemap` (изисква `site` в `astro.config.mjs` — placeholder домейн, TODO) и `public/robots.txt` с линк към sitemap.
- `/blagodarim` е `noindex` и не влиза в sitemap.
- Снимки през `astro:assets` (WebP/AVIF, с размери, lazy под първия екран).
- Без тежки слайдери; най-много един уеб шрифт с `font-display: swap`.

## 11. Технически решения

| Част | Избор |
| --- | --- |
| Рамка | Astro + TypeScript, статичен output |
| Интерактивни части | React само в `Calculator.tsx` и `QuoteForm.tsx` (`client:visible`) |
| Стилове | Tailwind CSS |
| Данни | `src/data/*.ts` |
| Тестове | Vitest за `src/lib/estimate.ts` |
| Хостинг | Render Static Site: build `npm run build`, publish directory `dist` |
| Форма | Web3Forms |
| Аналитика | Umami (`PUBLIC_UMAMI_WEBSITE_ID`); събития `call_click`, `viber_click`, `whatsapp_click`, `calculator_used`, `form_submit` |

```text
src/

    site.ts        # фирмени данни, контакти, работно време, райони, „защо нас“, vatNote

    services.ts    # услуги: slug, заглавие, текст, цена „от“, снимки, въпроси
```

